# Agent Instructions for PairSync

This file contains repository-scoped instructions for AI agents operating in this codebase.

## Agent skills

### Issue tracker

All PairSync work is tracked in Linear under the 'kleva-portfolio' team. Issues are created in the 'PairSync' project with appropriate labels. Linear issues are the source of truth for all development work. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses default triage label vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context layout: root `CONTEXT-MAP.md` pointing to per-context `CONTEXT.md` files across the monorepo. See `docs/agents/domain.md`.
