# Issue Tracker: Linear

**Tracker:** Linear  
**Team:** kleva-portfolio  
**Project:** PairSync  
**Workflow:** Linear issues are the source of truth for all development work.

## Workflow

We track all PairSync work in Linear under the 'kleva-portfolio' team. Issues are created in the 'PairSync' project with appropriate labels. Linear issues are the source of truth for all development work.

## Integration Notes

- The `to-tickets`, `triage`, `to-spec`, and `qa` skills will write to Linear when creating issues
- Issue creation uses the Linear API via the configured MCP server
- PRs as a request surface: **disabled** (default)

## PRs as a Request Surface

This setting is disabled by default. If you want external PRs to appear in the triage queue, enable this in the configuration.
